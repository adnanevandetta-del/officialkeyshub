**Takeaway:** copy keycense's *mix* (brand profiles + affiliates + Windows blogs + press), not brytesoft's.

## 2. Rules (keep these or the links hurt you)

1. **No buying links that pass ranking credit.** Paid placements (sponsored posts, paid news articles) are fine **only** if the link is marked `rel="sponsored"` or `nofollow`. Ask for that in writing. They're for traffic and brand, not rankings.
2. **No link exchanges, PBNs, "500 directories for $20" gigs, or comment spam.**
3. **Anchor text:** mostly "Official Keys Hub", "officialkeyshub.com", or a natural phrase. Keep exact keywords like "cheap windows key" to a small minority.
4. **Always disclose** that you run the store (Reddit, Quora, forums). Hidden self-promotion gets the domain banned on Reddit.
5. **Never say you're a Microsoft partner** and never post or buy fake reviews.
6. **Same name, email, phone everywhere:** Official Keys Hub · officialkeyshub@gmail.com · +1 601-975-6129.
