A Windows Server key isn't like a Windows 11 key. With Windows 11, one key covers one PC and that's it. With Server, **how many cores the machine has, how many virtual machines you run and how many people connect** all affect what you need. Get that right first, then find a good price.

## The short answer

- **Windows Server 2022 Standard** fits most small businesses: a physical server running up to two virtual machines.
- **Windows Server 2022 Datacenter** is for heavily virtualised hosts that run many virtual machines.
- **Client Access Licenses (CALs)** are needed for the users or devices that connect to the server, and **RDS CALs** for Remote Desktop sessions.

## 1. Cores: how the license is counted

Windows Server 2022 is licensed **per core**. The rules:

- Every physical core in the server must be licensed.
- A minimum of **8 cores per processor** and **16 cores per server** applies, even if the server has fewer.
- The standard base license covers 16 cores, which fits most small-business servers.

**Check before buying:** how many physical cores does your server have? On the server, open Task Manager → Performance → CPU and look at "Cores".

## 2. Standard or Datacenter?

| | Standard | Datacenter |
| --- | --- | --- |
| Virtual machines covered | 2 (when all cores are licensed) | Unlimited |
| Best for | File, print, domain controller, small app servers | Virtualisation hosts, many VMs |
| Storage Spaces Direct | No | Yes |

If you run more than a handful of virtual machines on one host, Datacenter usually works out cheaper than stacking Standard licenses.

## 3. CALs: the part people forget

The server license lets you run the server. **Every user or device that uses it also needs a CAL**:

- **User CALs** cover a person on any number of devices. Good when staff use several devices.
- **Device CALs** cover one device, used by anyone. Good for shared PCs or shifts.
- **RDS CALs** are needed on top for anyone using **Remote Desktop Services** to run apps or desktops on the server.

## Frequently asked questions

### Do I need CALs for Windows Server 2022?

Yes, for each user or device that accesses the server, except in a few cases such as the Essentials edition, which includes a limited number of users.

### How many virtual machines does Windows Server 2022 Standard allow?

Two virtual machines, when all physical cores in the host are licensed. Licensing the cores again adds two more.

### Can I upgrade from Windows Server 2022 Standard to Datacenter?

Yes. Standard can be converted to Datacenter in place by entering a Datacenter key with DISM, without reinstalling.

### Is Windows Server 2022 still supported?

Yes. It gets security updates until October 14, 2031. Mainstream support, which covers non-security fixes, ended on October 13, 2026.
