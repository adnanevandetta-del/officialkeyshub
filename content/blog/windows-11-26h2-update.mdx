Microsoft started rolling out **Windows 11 version 26H2** on **September 29, 2026**. It arrives in phases, so plenty of PCs haven't been offered it yet. And if you're still on 24H2 Home or Pro, you're running a version that no longer gets security updates.

Here's how to check where you are and get current.

## TL;DR

- **26H2 is free** for any PC already running genuine Windows 11. **You don't need a new product key.**
- It's a **small enablement update** for PCs on 24H2 or 25H2, so it installs quickly, usually with one restart.
- **24H2 Home and Pro stopped getting security updates on October 13, 2026.** If that's you, update now.
- PCs on **26H1**, which came only on certain new devices, can't move to 26H2.

## Step 1: Check which version you have

1. Press **Windows key + R**, type `winver` and press Enter.
2. The window shows your version, for example *Version 24H2*.

| Your version | What to do |
|---|---|
| 24H2 (Home or Pro) | **Update now.** Security updates have ended. |
| 25H2 | Update when it's offered. You're still supported. |
| 26H2 | You're on the latest version. |
| Still on Windows 10 | See [upgrading Windows 10 to Windows 11](/blog/upgrade-windows-10-to-windows-11-cheap). |

## Step 2: Install 26H2

**Through Windows Update (easiest)**

1. Open **Settings → Windows Update**.
2. Turn on **"Get the latest updates as soon as they're available"**.
3. Click **Check for updates**. If 26H2 is offered, click **Download & install**, then restart.

**If it isn't offered yet**

The rollout is staged, so Microsoft holds some PCs back until it's confident they're compatible. You can wait a few weeks, or use Microsoft's **Windows 11 Installation Assistant** from the official Windows 11 download page. Our [Windows 11 Pro download guide](/blog/windows-11-pro-download) walks through the official download options.

## Do you need a new product key for 26H2?

**No.** Feature updates such as 26H2 use the license you already have. Windows reactivates on its own through your digital license.

You only need a key if:

- **Windows says it isn't activated.** You'll see a watermark and a message under Settings → System → Activation. A [Windows 11 Pro key](/products/windows-11-pro) fixes that.
- **You want Pro features** on a Home PC, such as BitLocker, Remote Desktop or Hyper-V. See [how to upgrade Windows 11 Home to Pro](/blog/upgrade-windows-11-home-to-pro).
- **You're doing a clean install on new hardware** that has never had Windows 11 activated.

## Before you update

- **Back up anything important.** Feature updates are reliable, but a backup costs you nothing.
- **Free up some disk space.** Leave at least 20 GB free so the update has room to install.
- **Update your drivers**, especially graphics and storage, if your PC maker offers new ones.

## Frequently asked questions

### When was Windows 11 26H2 released?

Microsoft began rolling out Windows 11 26H2 on September 29, 2026. It's released in phases, so some PCs are offered it later than others.

### Is Windows 11 26H2 free?

Yes. It's a free update for any PC already running genuine, activated Windows 11.

### Do I need a new key to install Windows 11 26H2?

No. Your existing Windows 11 license carries over, and Windows reactivates automatically after the update.

### Why can't I see 26H2 in Windows Update?

The rollout is staged, so Microsoft offers it to compatible PCs gradually. Turn on "Get the latest updates as soon as they're available", or use the Windows 11 Installation Assistant. PCs on 26H1 can't move to 26H2.

### Is Windows 11 24H2 still supported?

Windows 11 24H2 Home and Pro stopped getting security updates on October 13, 2026. Enterprise and Education editions of 24H2 are supported until October 12, 2027. Read more in our [24H2 end of support guide](/blog/windows-11-24h2-end-support-october-2026).
