You've got an Office 2024 Professional Plus key and you go to Microsoft's site to download it. There's no download button. That's normal.

Professional Plus is the edition Microsoft makes for organisations (its official name is *Office LTSC Professional Plus 2024*), so it installs through Microsoft's free **Office Deployment Tool (ODT)** instead of the consumer setup page. Here's the whole process, step by step. It takes about 15 minutes.

> **Got a bind key?** Bind keys are redeemed to your Microsoft account at [setup.office.com](https://setup.office.com) and installed from there, so you can skip this guide. Not sure which type you have? See [Online vs Phone vs Bind keys](/blog/online-key-vs-phone-key-vs-bind-key).

## Before you start

1. **Uninstall other Office versions.** Many new PCs come with a Microsoft 365 trial preinstalled. Remove it in **Settings → Apps → Installed apps**. Having two Office versions installed side by side is the #1 cause of install and activation errors.
2. **Check you're on Windows 10 or 11.** Office 2024 doesn't run on Windows 7 or 8.1.
3. **Have your key ready.** It's in your order email.

## Step 1: download the Office Deployment Tool

1. Download the **Office Deployment Tool** from the [Microsoft Download Center](https://www.microsoft.com/en-us/download/details.aspx?id=49117). Always get the latest version.
2. Make a folder, for example `C:\Office2024`.
3. Run the downloaded file and extract it into that folder. You'll see `setup.exe` and some sample XML files.

## Step 2: create the configuration file

In `C:\Office2024`, create a new text file called `configuration.xml` (make sure it doesn't end in `.txt`) and paste this in:

```
<Configuration>
  <Add OfficeClientEdition="64" Channel="PerpetualVL2024">
    <Product ID="ProPlus2024Volume">
      <Language ID="en-us" />
    </Product>
  </Add>
  <RemoveMSI />
  <Display Level="Full" AcceptEULA="TRUE" />
</Configuration>
```

What it means:

- `ProPlus2024Volume` is Office 2024 Professional Plus.
- `PerpetualVL2024` is the Office 2024 update channel, with security updates until October 2029.
- `en-us` is English (US). Change it to `en-gb`, `fr-fr`, `de-de` and so on for another language.
- `RemoveMSI` cleans out old MSI-based Office installs (2010, 2013, 2016) automatically.

Don't want Access, or another app? Add `<ExcludeApp ID="Access" />` inside the `<Product>` block. Other IDs include `Outlook`, `OneNote` and `OneDrive`.

## Step 3: install

1. Open **Command Prompt as administrator** (search *cmd*, right-click, **Run as administrator**).
2. Run:

```
cd C:\Office2024
setup.exe /configure configuration.xml
```

The Office installer window appears and downloads about 3–4 GB. When it says **"You're all set"**, Office is installed.

Want an **offline installer** for several PCs? Run `setup.exe /download configuration.xml` first. That saves the files into the folder, then run `/configure` on each PC.

## Step 4: activate with your key

1. Open **Word** (or any Office app).
2. Go to **File → Account → Change Product Key**.
3. Enter your 25-character key and click **Activate**.

Under *Product Information* it should now say **Product Activated – Microsoft Office LTSC Professional Plus 2024**.

### Prefer the command line?

In an admin Command Prompt:

```
cd "C:\Program Files\Microsoft Office\Office16"
cscript ospp.vbs /inpkey:XXXXX-XXXXX-XXXXX-XXXXX-XXXXX
cscript ospp.vbs /act
```

Then check it with `cscript ospp.vbs /dstatus`. You want **LICENSE STATUS: ---LICENSED---**.

### Phone key?

If you bought a phone-activation key, the activation wizard offers **"I want to activate the software by telephone"**. Choose your country, call the automated number or use the on-screen code steps, and type in the confirmation ID.

## Common errors and fixes

### "This product key is for a volume-licensed version that isn't installed"

You entered a Pro Plus key into a **different** Office, usually a preinstalled Microsoft 365 or Office Home. Uninstall that version and install Pro Plus with the ODT as shown above.

### "We couldn't find any Office products" when you sign in

Pro Plus doesn't need, or show up in, a Microsoft account. You can sign in to Office for OneDrive, but activation comes from the key, not the account.

### Setup stops with error 30015, 30088 or "Something went wrong"

Usually leftovers from an older Office. Run Microsoft's **Office uninstall troubleshooter** (search *"uninstall Office from a PC"* on support.microsoft.com), restart, and run `setup.exe /configure` again.

### "This key has been used too many times"

Use phone activation (above), or contact us for a replacement. See [Windows or Office key blocked?](/blog/windows-product-key-blocked) for what each error means.

## Frequently asked questions

### Where can I download Office 2024 Professional Plus?

Microsoft doesn't offer a consumer download page for Professional Plus. You install it with Microsoft's free Office Deployment Tool, using a configuration file with the Product ID ProPlus2024Volume and the channel PerpetualVL2024.

### Is there an Office 2024 Professional Plus ISO?

Microsoft doesn't publish a public ISO for Office 2024 Professional Plus. Use `setup.exe /download configuration.xml` with the Office Deployment Tool to create your own offline installation files instead. Avoid ISOs from third-party sites, which can be modified.

### Do I need a Microsoft account to activate Office 2024 Pro Plus?

No. Online and phone keys activate Office 2024 Professional Plus directly with the product key. Only bind keys are redeemed to a Microsoft account.

### Can I install Office 2024 Pro Plus alongside Microsoft 365?

It's not recommended. Two Click-to-Run Office versions on one PC often cause activation errors. Uninstall Microsoft 365 first.

### Does Office 2024 Professional Plus get updates?

Yes. Installed on the PerpetualVL2024 channel, it receives security and quality updates through Microsoft Update until 9 October 2029.
